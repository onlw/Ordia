# Ordia

高性能、高颜值的开源跨平台办公套件，基于 Rust + [GPUI](https://www.gpui.rs) + [GPUI Kit](https://github.com/longbridge/gpui-kit)。

> 🚧 **规划阶段**。第一个产品是 **Ordia 表格**（对标 Excel / WPS 表格），平台为 macOS 和 Windows。

## 为什么做 Ordia

- **快**：原生 GPU 渲染，秒开大文件，滚动不卡
- **好看**：现代、克制、有质感，支持亮色和暗色主题
- **放心**：打开别人的 Excel/WPS 文件不乱，保存时不破坏自己不认识的内容
- **干净**：无广告、无强制登录、不收集数据、Apache-2.0 开源
